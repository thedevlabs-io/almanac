## The clock runs when two things are true

**Your VS Code window has focus.** Switch to a browser, Slack or another app and
the clock stops immediately. Focus is what keeps the count honest.

**Something happened in the window recently.** Anything counts:

- typing, scrolling or moving the cursor in a file
- running a command in the terminal, and output arriving from one
- stepping through a debugger, or a task running
- switching tabs, opening a preview, using the Simple Browser

"Recently" means the last 15 minutes by default, so reading a long file or
thinking about a design is not scored as idle.

Nothing else opens the clock. A window left focused overnight with nothing
happening in it records nothing.
